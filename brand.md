# Brand — Ringio

_Status: founder-selected-bauhaus-direction_

Ringio brings trusted savings circles on-chain through a functional Bauhaus system: visible structure, primary geometry, direct language, and no ornamental Web3 gloss.

## Direction

- Archetype: Bauhaus / functional modernism
- Density: Comfortable; spacious at discovery, compact-but-readable in live circle data
- Surface: Off-white paper, hard grid lines, flat color blocks, squared panels
- Type mood: Geometric, direct, civic, technical
- Motion: Short and causal; `cubic-bezier(0.23, 1, 0.32, 1)`, never bounce

The page may be asymmetric, but transaction review, tables, forms, and monetary summaries remain aligned and calm. Geometry communicates state: circles identify members/turns, squares hold data, and lines show sequence.

### Dark

- Background: `#171714`
- Elevated: `#22221E`
- Foreground: `#F4F0E6`
- Muted foreground: `#C3BDAF`
- Functional red: `#FF6A54`

Primary colors are functional, not confetti. Near-black is the default action color. Red marks due/urgent states, blue marks AI/discovery and informational state, yellow marks the current turn. Green remains reserved for confirmed success. Color is always paired with copy, an icon, or a pattern.

## Typography

- UI and display: Geist Sans, regular / medium / bold; large headings use tight tracking
- Amounts, addresses, group codes, slots, and times: Geist Mono with tabular numerals
- Labels: short uppercase text with loose tracking
- Voice hierarchy: sentence case body text; no gradient text, faux-handwriting, or decorative serif

## Components

- Cards: square or 4px radius, 1px ink border; no glassmorphism
- Primary buttons: ink fill on paper; red is reserved for time-sensitive action
- AI surfaces: blue rule/block and a clear `AI + rules` mode label
- Current recipient: yellow field with ink text, never yellow text on paper
- Avatars: circles; data containers: rectangles; progress: lines and numbered nodes
- Shadows: none on data panels; one deliberate hard offset shadow may appear on a first-impression composition

## Voice

Ringio is direct and specific. It states what is locked, what is due, which protection scope applies, and whether a result came from deterministic rules or GPT‑4o. It never says “AI found the perfect group,” “risk-free,” or “trust the code.”

The matcher behaves like a careful guide, not a salesperson. It explains why a group fits, names tradeoffs, and refuses to invent availability or guarantees. A group code identifies a public catalog entry; it is not an invitation secret or proof of membership.

The cultural reference is handled with respect and modern clarity. Prefer “circle,” “turn,” “contribution,” “payout,” and “post-payout coverage” over dense protocol jargon.

## Usage

Do:

- Make the grid and information hierarchy visible.
- Use one primary color per local surface.
- Show `AI`, `rules fallback`, `demo`, `devnet`, and `on-chain` states explicitly.
- Render USDC and percentages with mono tabular numerals.
- Keep financial confirmations symmetric even when the surrounding page is asymmetric.

Do not:

- Use all three primary colors as equal decoration in every section.
- Treat a short group code as access control.
- Send wallet addresses, phone numbers, invitation secrets, or private group chat to an LLM.
- Claim a recommendation is financial advice or that collateral removes all default risk.
- Use violet/blue Web3 gradients, rounded-everything cards, glass blur, pure black, or `transition-all`.
